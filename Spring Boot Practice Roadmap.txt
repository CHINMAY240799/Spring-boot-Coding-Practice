**Important challenge – Bank transfer**

Create two entities:

- Account (accountId, accountHolder, balance)
- Transaction (transactionId, fromAccount, toAccount, amount)

Implement:

```
public void transferMoney(
    Long fromAccount,
    Long toAccount,
    BigDecimal amount
)
```

Requirements:

1. Check whether both accounts exist.
2. Check whether the sender has sufficient balance.
3. Deduct money from sender.
4. Add money to receiver.
5. Save transaction details.
6. Roll back everything if any operation fails.

Use `@Transactional`.

This is a very good way to demonstrate your understanding of real-world backend development.
